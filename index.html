The Cost of Ambiguity

Reflection Prompt

  • What was your request?
  • What did the model assume incorrectly?
  • What was the cost (time, risk, reputation)?

Diagnostic Poll

  • Missing business context?
  • No constraints or boundaries?
  • Output format unspecified?
  • Wrong audience or tone?
00:10-00:25

The Human Delegation Lab

Paired simulation: Architect writes instructions, Builder executes with constrained interpretation.

Round 1: Raw Request

  • Architect gives a 1-sentence request.
  • Builder executes literally.
  • Measure mismatch and rework.

Round 2: Structured Request

  • Architect rewrites with C.L.E.A.R.+ fields.
  • Builder executes again.
  • Compare quality and speed delta.

Prompt Makeover Studio

Before

"Make a project plan for launching our service."

  • No scope
  • No output spec
  • No failure boundaries

After (C.L.E.A.R.+)

Context: pre-revenue B2B startup, 4-week runway.
Limits: no paid ads, no legal claims.
Expected: 4-week plan table + risk log + owners.

01:00-01:20

Live Iteration Crucible

3-Step Iteration Loop

  1. Diagnose: Identify which C.L.E.A.R.+ field failed.
  2. Isolate: Change one variable only (scope, role, constraints, format).
  3. Constrain: Add explicit exclusions and a verification gate.

Peer audit question: "What assumption is still unconstrained?"

01:20-01:30

Synthesis, Action Plan & Post-Test

Post-Test

  • Rewrite one flawed request with C.L.E.A.R.+
  • Add two negative constraints
  • Define pass/fail output criteria

Action Plan

  • Use C.L.E.A.R.+ in one real task this week
  • Run Diagnose-Isolate-Constrain loop
  • Share outcomes with your team
